# [XS] aws-lc-rs extras on demand

## Goal

Each aws-lc-rs algorithm beyond ring's set gets a quest when a consumer asks for it: ML-KEM-512 and ML-KEM-1024, RSA-OAEP encryption, AES-CBC, AES-CTR and other cipher modes, AES key wrap, KBKDF and SSKDF, AES-GCM-SIV, SHA-224, and ML-DSA. This quest only waits; check new issues and MoQ's needs when triaging, plan the asked-for algorithm with `/quest-plan`, and delete this quest once the list is empty or abandoned.

## Plan

Decided by the maintainer on 2026-10-30, planning ring and aws-lc-rs parity.
