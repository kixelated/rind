# [XS] SHA-512/256

## Goal

rind offers SHA-512/256 (FIPS 180-4's truncated SHA-512 with its own initial value), as ring's `digest::SHA512_256` does.

## Plan

Decided by the maintainer on 2026-10-30, planning ring and aws-lc-rs parity.

- Reuse the SHA-512 compression on every backend; only the initial value
  and output length differ.
