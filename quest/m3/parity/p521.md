# [M] P-521

## Goal

rind does ECDH and ECDSA on P-521, on every backend, behind the same API as P-256 and P-384.

## Plan

Decided by the maintainer on 2026-10-30, planning ring and aws-lc-rs parity.

- Needed by [rustls provider parity](/quest/m3/parity/rustls.md), whose
  aws-lc-rs counterpart offers secp521r1 and ECDSA P-521.
- Pick the fastest source, preferring a verified one when it is as fast
  (`AGENTS.md`): s2n-bignum has P-521 field and point routines
  for x86_64 and aarch64, and fiat-crypto covers armv7 as it does P-384.
